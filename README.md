## Introduction

This project is my first relatively formal project. Since I’m not very familiar with some aspects of it, I focused almost exclusively on the code itself, so there may still be some oversights in certain areas.

Development began using the official Godot template ([godot-cpp-template](https://github.com/godotengine/godot-cpp-template)), and the project runs on [GodotEngine](https://github.com/godotengine/godot) 4.7.2

## Compilation/Build

### Dynamic Library Build

This project is built using the C++20 standard,

This project uses SCons for building

```
scons
```

CMakeLists.txt is retained in the project as a backup

Building the dynamic library for the Android platform requires NDK version `28.1.13356709`
